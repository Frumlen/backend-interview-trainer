# Тренажёр backend-собеседования

Интерактивный тренажёр для подготовки к техническому собеседованию backend-разработчика: **сеть, базы данных, алгоритмы, Go, system design**.

- **Learn** — каждая тема объясняется цепочкой «проблема → решение → новая проблема», с аналогиями и готовой формулировкой для собеседования. Рядом — краткий ответ на трёх уровнях (Junior / Middle / Senior) со схемами, в том числе пошаговыми.
- **Recall / Review** — вопросы на вспоминание с самооценкой и интервальным повторением.
- **Practice** — задачи на применение, разборы решений.
- **Exam** — готовые наборы вопросов по разделам и смешанный экзамен.
- **Map** — карта связей между темами; термины в тексте подсвечиваются, при наведении — определение.

Всё работает офлайн в одном файле `index.html`: без сервера, без регистрации. Прогресс хранится в браузере (localStorage) — на каждом устройстве свой.

## Как открыть

- Онлайн: страница GitHub Pages этого репозитория (`https://<логин>.github.io/<репозиторий>/`).
- Локально: скачать `index.html` и открыть двойным кликом.

Клавиши: `1`–`6` — режимы, `/` — поиск, `Space` — показать ответ, `⌘/Ctrl+Enter` — отправить, `N` — дальше.

## Структура

```
index.html            собранная страница (результат сборки, руками не править)
content/              весь материал курса в JSON — это и есть «исходники» тренажёра
docs/content-guide.md правила: как устроены файлы и в каком стиле писать
app/                  интерфейс: шаблон, стили, JS, встроенные библиотеки
tools/                сборка и проверки (Python 3 без зависимостей; Node — только для проверки схем)
```

## Как добавить материал

1. Прочитай [`docs/content-guide.md`](docs/content-guide.md) — там схема файлов, правила подачи и образцы.
2. Добавь тему в `content/registry.json` и создай `content/concepts/<id>.json` по образцу (эталон подачи — `content/concepts/tcp.json`).
3. Проверь и собери:
   ```bash
   python3 tools/check_fragment.py <группа>   # быстрая проверка группы, например 07-go-slice
   python3 tools/build.py                     # полная валидация и сборка index.html
   ```
4. Закоммить изменения в `content/` вместе с новым `index.html`.

### Если материал добавляет ИИ-ассистент

Дай ему этот репозиторий и задачу вида:

> Добавь в тренажёр тему «…». Сначала полностью прочитай `docs/content-guide.md` и образцы, которые там перечислены (`content/concepts/tcp.json`, `udp.json`, `go-slice-append.json`), и пиши в точности в том же стиле и по той же схеме. Файлы в `app/` не меняй. В конце прогони `tools/check_fragment.py`, `tools/build.py` и `tools/check_visuals.js` — все проверки должны быть без ошибок.

## Публикация на GitHub Pages

Settings → Pages → Source: **Deploy from a branch**, ветка `main`, папка `/ (root)`. После каждого `git push` с новым `index.html` страница обновляется сама через минуту-две.

## Сборка

```bash
python3 tools/build.py            # content/ → index.html (+ course.json); при ошибках валидации exit 1 и файлы не пишутся
python3 tools/build.py --check    # только валидация
python3 tools/build.py --force    # записать даже с ошибками (для отладки)
```
